# Спецификация prolanwo++ v0.1

## 1. Общее

**Название:** prolanwo++  
**Расширение файлов:** `.pw`  
**Тип:** интерпретируемый  
**Типизация:** динамическая, с объявлением типа

## 2. Ключевые слова

Все ключевые слова **нечувствительны к регистру**.

| Ключевое слово | Назначение |
|---------------|-----------|
| `variable` | объявить переменную |
| `change variable` | изменить переменную |
| `notchan` | защитить от изменений |
| `briout` | вывод |
| `input` | ввод |
| `if` / `or if` / `or` | условие |
| `replay` / `begin` | цикл |
| `function` / `return` | функция |
| `array` / `new object` | массив |
| `import` | импорт модуля |
| `history` | история переменной |
| `rollback` | откат значения |
| `stop` / `stopfurt` | выход/продолжить цикл |

## 3. Типы

- `line` — строка
- `number` — число
- `TruFal` — булево
- **без типа** — переменная с любым значением (`Variable[имя]_...`)

## 4. Операторы

| Оператор | Значение |
|----------|----------|
| `+` | сложение / склейка строк |
| `-` | вычитание |
| `*` | умножение |
| `/` | деление |
| `==` `!=` | сравнение |
| `<` `>` `<=` `>=` | сравнение |
| `$$` | логическое И |
| `$#` | логическое ИЛИ |

## 5. Структура программы

Программа — последовательность инструкций, каждая заканчивается точкой с запятой `;`.

## 6. Комментарии

- `\"..."/` — однострочный
- `\$"..."$/` — многострочный

## 7. Ограничения

- Массив: до **100 000** элементов (`_unlimited` — без лимита)
- `random.number`: до **100 000**
- Переменная типа number: до **1 000 000**

## 8. Пример программы

\"Калькулятор факториала"/

function Factorial(number[n]) =(
    variable number[result]_1;
    variable number[i]_1;
    replay (i <= n) begin {
        change variable[result]_result * i;
        change variable[i]_i + 1;
    }
    return result;
)

variable number[n]_input("Введите число: ");
briout("Факториал: " + Factorial(n));
